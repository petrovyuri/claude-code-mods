Моды для Claude Code

Три мода для окна Claude Code: полоса лимитов над полем ввода, подсказка после ответа и вопрос перед опасной командой.

claude plugin marketplace add petrovyuri/claude-code-mods
Как установить

limits-cache v0.0.1

Полоса над полем ввода

Вы видите остаток лимитов и время до сброса кеша промпта.

  • Лимиты аккаунта за пять часов и за семь дней: процент и время до сброса.
  • Полоса кеша зелёная, пока осталось больше половины, потом жёлтая и красная.
  • Кнопка ↻ прогревает кеш скрытым форком сессии, «Авто» делает это за три минуты до конца.
  • Закрытую полосу вы вернёте командой /limits.

Зачем прогревать кеш

Claude Code хранит контекст сессии в кеше промпта. Пока кеш жив, каждый запрос читает контекст за 10% цены входа и продлевает кешу жизнь. Если вы ушли дольше, чем живёт кеш, следующее сообщение записывает весь контекст заново: за 125% цены у 5-минутного кеша и за 200% у часового.

Для прогрева мод отправляет короткий запрос: он только читает кеш, и отсчёт начинается заново. Ответ после паузы к тому же приходит быстрее: контекст не нужно обрабатывать заново.

×0,1прогрев: чтение контекста из кеша
×2остывший часовой кеш: запись всего контекста заново

Пример: в сессии 200 тысяч токенов контекста. Прогрев стоит как 20 тысяч токенов входа, перезапись часового кеша как 400 тысяч, в 20 раз дороже. Множители взяты из тарифов API Anthropic. Если вы не пишете час, «Авто» выключается: держать кеш дальше нет смысла.

claude plugin install limits-cache@petrovyuri-mods --scope user

Кнопка «Что дальше?» под ответом и панель

После перерыва кнопка под ответом напомнит, на чём вы остановились и что написать дальше.

  • Ниже готовые сообщения карточками. Вы выбираете одно, и оно попадает в чат.
claude plugin install next-step@petrovyuri-mods --scope user

panic-button v0.0.1

Вопрос в чате

Перед командой, которую не отменить, Claude останавливается и спрашивает вас. Haiku одной фразой объясняет, что именно сломается.

  • Файлы: rm -rf, Remove-Item -Recurse, rmdir /s.
  • Git: push --force, reset --hard, clean -f, branch -D.
  • Базы: DROP TABLE, TRUNCATE, DELETE без WHERE.
  • Секреты: чтение и правка файлов .env.
  • После «Запретить» Claude не повторяет команду, не ищет обходной путь и спрашивает, как быть.
  • Всю команду видно в превью варианта, длинная цепочка ничего не спрячет.
claude plugin install panic-button@petrovyuri-mods --scope user

Установка

  1. Подключите marketplace один раз.

    claude plugin marketplace add petrovyuri/claude-code-mods

  2. Поставьте мод для всех проектов. Команду для каждого мода вы найдёте в его описании выше.

    claude plugin install next-step@petrovyuri-mods --scope user

  3. В открытой сессии выполните /reload-plugins. Новую сессию перезагружать не нужно.

Обновить мод до новой версии, затем выполнить /reload-plugins:

claude plugin update next-step@petrovyuri-mods

Без marketplace: скачайте архив мода и распакуйте его в папку .claude/skills/ проекта. Claude Code загрузит мод при старте следующей сессии в этом проекте.

Все версии и изменения лежат в репозитории: у каждого мода свой README и CHANGELOG.
