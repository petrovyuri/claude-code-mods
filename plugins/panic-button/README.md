# panic-button

![версия](https://img.shields.io/badge/версия-0.0.7-c6613f) ![Claude Code](https://img.shields.io/badge/Claude_Code-мод-30302e)

Тревожная кнопка. Перед командой, которую не отменить, Claude останавливается и спрашивает вас.

## Как выглядит

```
❗ Опасное действие: удаление таблицы или базы данных.
Команда только выводит текст "DROP TABLE demo" в консоль, таблица demo не удаляется.
Команда: `echo "DROP TABLE demo"`
Разрешить?

  ◉ Разрешить
  ○ Запретить
      Claude не выполнит команду и спросит, как быть
  ○ Объяснить
      Claude подробно расскажет, что сделает команда и зачем она нужна, и спросит снова
  ○ Другое
```

Во второй строке Haiku одной фразой объясняет, что именно команда удалит, перезапишет или раскроет. Если Haiku не ответит за 6 секунд, вопрос придёт без неё.

## Что останавливает

| Группа | Команды |
|---|---|
| Файлы | `rm -rf`, `Remove-Item -Recurse`, `rmdir /s`, `del /s` (уборку Claude в своей временной папке scratchpad не спрашивает) |
| Git | `push --force`, `reset --hard`, `clean -f`, `branch -D` |
| Базы данных | `DROP TABLE`, `DROP DATABASE`, `TRUNCATE`, `DELETE` без `WHERE` |
| Секреты | Чтение и правка файлов `.env`, `.env.local`, `.env.production` (шаблоны `.env.example` и зашифрованный sops `.env.enc` можно, как и проверку, есть ли файл: `ls .env`, `test -f .env`) |

## Ответы

- **Разрешить**: команда выполняется.
- **Запретить**: Claude не выполняет команду, не повторяет её, не ищет обходной путь и спрашивает, как быть.
- **Объяснить**: модель этой сессии, которая знает задачу, рассказывает, что команда сделает по шагам, зачем она нужна и что будет, если её запретить. Объяснение приходит во втором вопросе с вариантами «Разрешить» и «Запретить». Если ответа нет, объясняет Haiku по одной команде, а о цели говорит как о предположении.
- **Другое** или закрытый вопрос: тоже запрет. Пункт «Другое» добавляет сам диалог Claude Code, мод его убрать не может.

Всю команду целиком видно в превью варианта, длинная цепочка ничего не спрячет. Если мод сам сломается, команда будет остановлена на всякий случай.

## Установка

```bash
claude plugin marketplace add petrovyuri/claude-code-mods
```

```bash
claude plugin install panic-button@petrovyuri-mods --scope user
```

В открытой сессии выполните `/reload-plugins`.
