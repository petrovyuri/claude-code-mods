# Изменения panic-button

## 0.0.6

- Новый вариант «Объяснить». Модель этой сессии, которая знает задачу, рассказывает, что команда сделает по шагам, зачем она нужна и что будет, если её запретить, а потом вопрос «Разрешить / Запретить» приходит снова. Если модель сессии не ответила, объясняет Haiku по одной команде.
- Короткие имена после `cd` в scratchpad, например `cd …/scratchpad && py x.py && rm -rf __pycache__`, больше не вызывают тревогу. Это работает, только если команда начинается с `cd` в scratchpad, больше никуда не переходит (`cd`, `pushd`, `Set-Location`, `source`, `eval`, `exec`, `.`) и доходит до удаления через одни `&&`. Если между ними есть `;`, `||`, `&` или перенос строки, вопрос остаётся: при неудачном `cd` удаление запустилось бы в папке проекта.
- Пункт «Другое» по-прежнему виден: его добавляет сам диалог Claude Code, мод не может его убрать. Ответ в нём, как и раньше, запрещает команду.

## 0.0.5

Исправление безопасности для 0.0.4: исключение для scratchpad можно было обойти через переменную.

- Разбиение на слова в bash: пробел в значении (`d="…/scratchpad/a /home/u"; rm -rf $d`) или свой `IFS`.
- Другие способы задать переменную: `for d in`, `read d`, `printf -v d`, `Set-Variable`, `foreach ($d in …)`, `$d, $e = …`.

Теперь в целях удаления нельзя пробелы, а команда с `IFS` не получает исключения. Переменной можно задать значение только одним присваиванием, во всех остальных местах её можно только читать.

## 0.0.4

Исправление безопасности для 0.0.3: исключение для scratchpad можно было обойти, и удаление за его пределами проходило без вопроса.

- Раскрытие фигурных скобок, например `rm -rf …/scratchpad/cmp{,/../../..}`, и подстановка через обратные кавычки.
- Второй путь в том же аргументе: PowerShell-массив `$d,C:\Users`.
- Цель, принятая за флаг: `-Path:C:\Users` и `/c`, корень диска C в Git Bash.
- Переменная, которая получает путь в scratchpad только после удаления.

Теперь цель удаления пропускается, только если это абсолютный путь, который начинается с scratchpad, состоит из букв, цифр и простой пунктуации и не ведёт наверх через `..`.

## 0.0.3

- Рекурсивное удаление внутри временной папки сессии Claude (`…\Temp\claude\…\scratchpad`) больше не вызывает тревогу: это Claude убирает за собой.
- Исключение осторожное: каждая цель удаления должна лежать в scratchpad, буквальным путём или переменной с одним буквальным значением в той же команде. Пути с `..`, вычисляемые значения и любые цели за пределами scratchpad по-прежнему вызывают вопрос.
- Если в цепочке опасных шагов несколько, вопрос называет настоящий, а не уборку scratchpad.

## 0.0.2

- `.env.enc`, зашифрованный sops, больше не вызывает тревогу: ни при чтении файла, ни когда это имя просто встречается в тексте команды, например в строке для `echo`.

## 0.0.1

Первая публичная версия.

- Вопрос «Разрешить / Запретить» перед опасными командами: удаление файлов, git с перезаписью, удаление данных в базе, доступ к `.env`.
- Haiku одной фразой объясняет, что сломается.
- Вся команда целиком видна в превью варианта.
