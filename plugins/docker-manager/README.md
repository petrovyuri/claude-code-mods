# docker-manager

![версия](https://img.shields.io/badge/версия-0.0.2-c6613f) ![Claude Code](https://img.shields.io/badge/Claude_Code-мод-30302e)

Панель Docker внутри Claude Code, как у плагина Docker в VS Code. Контейнерами управляете вы сами, кнопками, без запросов к Claude.

## Как открыть

Команда `/docker` в чате. Панель встаёт сбоку и, пока открыта, обновляется каждые 5 секунд.

## Что умеет

| Вкладка | Что видно | Что можно сделать |
|---|---|---|
| Контейнеры | Compose-проекты деревом и «Отдельные контейнеры», у группы счётчик «запущено / всего»; у контейнера статус, образ и опубликованные порты ссылками на `localhost` | Старт, Стоп, Рестарт, Логи (последние 300 строк, stdout и stderr по времени), Копировать ID, Удалить; у проекта Старт, Стоп, Рестарт и `compose down` |
| Образы | Репозиторий и тег, размер, возраст, сколько контейнеров используют | Удалить образ, удалить висячие (`docker image prune`) |
| Сети | Имя, драйвер, область, compose-проект | Удалить (кроме `bridge`, `host`, `none`), удалить неиспользуемые |
| Тома | Имя, драйвер, compose-проект | Удалить, удалить анонимные (`docker volume prune`) |

Удаление контейнера, образа, сети или тома, `compose down` и очистка спрашивают второй раз: «Да / Отмена». Результат действия показывается строкой над списком и пропадает сам: успех через 5 секунд, ошибка через 15.

Если Docker Desktop не запущен, панель так и скажет.

## Что нужно

- Docker CLI в `PATH` (Docker Desktop или Docker Engine).
- Для `compose down` — Docker Compose v2. Compose-файл не нужен: проект находится по имени.

## Установка

```bash
claude plugin marketplace add petrovyuri/claude-code-mods
```

```bash
claude plugin install docker-manager@petrovyuri-mods --scope user
```

В открытой сессии выполните `/reload-plugins`, затем `/docker`.
